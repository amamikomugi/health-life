# あまみこむぎの健康生活

食事・体重・Apple Healthの歩数と消費カロリーの推移を確認するサイトです。

記録はCodexチャットで入力し、日本時間で日付を管理します。食事は登録・訂正のたびに公開します。定期更新は毎日01:00（日本時間）で、freddyから昨日までのヘルスケアデータを取得してから公開します。今日までの未取得の歩数は表示・計算で0歩として扱い、原本には未取得を保持します。0歩で活動消費が未取得の場合は活動0kcalを仮定し、取得済みの安静時消費を総消費にします。仮計算と表示し、原本は未取得を保持します。安静時消費・食事の不明値は補完せず、日合計と食事の二重加算を防ぎます。

- 総消費 = 活動消費 + 安静時消費（活動未取得かつ0歩は活動0kcalを仮定、安静時は取得済みの値が必要）
- 食事の差 = 摂取量 − 目標候補
- 体重は測定日ごとに記録できます。以前の週単位の記録も表示し、未記録の期間は補間しません。

認証情報・過去チャットの全文・同期元の生データは公開しません。
