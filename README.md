# あまみこむぎの健康生活

食事・週ごとの体重・Apple Healthの歩数と消費カロリーの推移を確認するサイトです。

記録はCodexチャットで入力し、日本時間で日付を管理します。食事は登録・訂正のたびに公開します。定期更新は毎日01:00・14:00（日本時間）です。01:00にはfreddyからヘルスケアの値を取得し、14:00には保存済みデータを使って更新します。未取得の値は0にせず、日合計と食事の二重加算を防ぎます。

- 総消費 = 活動消費 + 安静時消費（両方の取得時のみ）
- 食事の差 = 摂取量 − 目標候補
- 体重は月曜開始の週別。未記録週は補間しません。

認証情報・過去チャットの全文・同期元の生データは公開しません。
